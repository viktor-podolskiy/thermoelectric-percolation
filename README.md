The project contains a COMSOL Multiphysics model and a script to control this model to calculate thermoelectric properties of composites where a semiconductor host is impregnated with metallic inclusions. 
To run, 
- Download the files
- Run the Matlab script

The script will generate the composites, solve for the electric, thermal, and thermoelectric properties of these composites, analyze the structure of conducting clusters, and will save the final data.
